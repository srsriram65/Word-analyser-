# Application 3 - Word Analyzer

## Aim

To analyze text and find the total number of words, characters, and frequency of each word.

## Features

- Counts total words
- Counts total characters
- Finds word frequency
- Simple web interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Example Input

hello world hello python world hello

## Example Output

Total Words: 6

Total Characters: 35

Word Frequency:

hello : 3
world : 2
python : 1
